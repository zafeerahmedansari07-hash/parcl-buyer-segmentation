Executive Summary

Real estate analytics platforms often face challenges with generalized customer targeting due to high buyer diversity. Without granular segmentation, marketing strategies remain inefficient, lead conversion rates plateau, and property recommendations lack personalization.This project addresses these challenges for Parcl Co. Limited by implementing an end-to-end Machine Learning pipeline. By processing and merging transaction and client datasets (7,305 records), engineering 76 standardized features, and applying K-Means clustering ($K=4$), we successfully identified four distinct buyer personas: Global Investors (C1), First-Time Buyers (C2), Corporate Buyers (C3), and Luxury Investors (C4).The resulting insights were deployed into an interactive Streamlit Market Intelligence Dashboard, enabling real-time filtering across geographic regions, financing preferences, and acquisition behaviors to drive data-informed real estate marketing and investment decisions.1. Project Overview & Objectives1.1 Context & BackgroundParcl Co. Limited operates in a dynamic real estate environment catering to diverse demographic and institutional groups. The buyer pool includes individual homebuyers, institutional investors, high-net-worth individuals, first-time purchasers, and international buyers. Treating this heterogeneous audience with a uniform marketing and sales strategy leads to sub-optimal client engagement and missed investment conversions.1.2 Problem StatementParcl currently lacks an automated, data-driven framework to uncover:Underlying structural patterns across diverse buyer categories.Investment motivations across varied demographic profiles.Geographic variations in property acquisition behavior.Specific customer financing dependencies (loan reliance vs. equity purchases).1.3 Project ObjectivesData Integration & Cleaning: Clean, normalize, and merge transactional property data with client demographic profiles.Unsupervised Machine Learning: Implement K-Means clustering to partition the customer base into actionable segments.Model Validation: Quantitatively validate cluster selections using Elbow Method analysis and Silhouette Score optimization.Dashboard Deployment: Deliver an executive Streamlit dashboard with real-time multi-dimensional filtering for stakeholders.2. 2.1 Data Ingestion & CleaningThe pipeline ingests two primary datasets linked via foreign key relationships (client_id in clients data matching client_ref in properties data):Clients File: Demographic attributes (date_of_birth, gender, country, region, client_type, satisfaction_score, referral_channel).Properties File: Transaction records (listing_id, tower_number, transaction_date, unit_category, floor_area_sqft, sale_price, acquisition_purpose, loan_applied).Data cleaning steps executed:Key Alignment & Merging: Inner join conducted on primary and foreign keys, producing a unified matrix of 7,305 records across 21 raw columns.String Cleaning: Removed currency markers ($) and formatting commas from numerical fields (sale_price) to convert them to float values.Imputation: Derived missing age values from date_of_birth using the median age. Missing satisfaction_score records were imputed using the column median.2.2 Feature Engineering, Encoding, & ScalingTo prepare the dataset for distance-based clustering algorithms:Feature Extraction: Computed client age from date-of-birth timestamps relative to the current analysis period.Categorical Encoding: Applied OneHotEncoder(drop='first', sparse_output=False) across nominal features (client_type, gender, country, region, acquisition_purpose, loan_applied, referral_channel, unit_category), converting categorical parameters into dummy variable representations.Numerical Scaling: Standardized continuous variables (age, satisfaction_score, floor_area_sqft, sale_price) using StandardScaler to achieve zero mean and unit variance ($Z = \frac{x - \mu}{\sigma}$), preventing feature magnitude bias in Euclidean distance calculations.The final transformed design matrix $X_{\text{scaled}}$ comprised 7,305 rows and 76 engineered features.2.3 Optimal Cluster Selection ($K=4$)To determine the optimal value for $K$, multiple iterations of K-Means were fitted across $K \in [2, 6]$. Performance was evaluated using two complementary metrics:Elbow Method (Inertia / Within-Cluster Sum of Squares):Evaluated the reduction in inertia as $K$ increased. A distinct bend (elbow point) occurred at $K = 4$, indicating diminishing returns in variance explained for higher values of $K$.Silhouette Score Analysis:Calculated cluster cohesion and separation quality:
$$S_i = \frac{b_i - a_i}{\max(a_i, b_i)}$$
The silhouette plot demonstrated a clear inflection plateau between $K = 3$ and $K = 4$ ($S \approx 0.153$), followed by a sharp drop at $K = 5$ ($S \approx 0.126$).Based on mathematical alignment between the Elbow curve and Silhouette plateau, $K = 4$ was chosen as the optimal cluster architecture.3.
